# 触发符、搜索与快捷键

## 触发符

| 规则 | 值 |
| --- | --- |
| 默认 | `#` |
| 数量 | 最多 8 个 |
| 单个长度 | 1–8 个字符 |
| 保留字符 | `/`、`@`（分别属于指令与引用） |
| 唯一性 | 不允许重复 |
| 空白 | 不允许 |

任意一个触发符都能打开同一个面板。

- 触发符必须出现在词的边界：开头、空白之后，或标点之后
- 紧跟字母、数字或下划线时不触发，例如 `abc#wt`
- 查询只接受文字、数字、下划线、连字符和中点；出现空白即关闭
- 多个触发符在同一位置重叠时取最长，例如同时配置 `#` 和 `##`，输入 `##wt` 按 `##` 解析

示例：

```text
#wt          按简码 wt 搜索
#纯提        按正文片段搜索
;;方案       以 ;; 为触发符
```

## 搜索

按以下优先级排序：

1. 简码精确匹配
2. 简码前缀匹配
3. 简码子序列匹配
4. 名称匹配
5. 正文子串匹配
6. 正文子序列匹配

查询为空时按配置顺序列出短语。空格分隔多个词时要求全部命中。

## 快捷键

| 按键 | 行为 |
| --- | --- |
| `↑` / `↓` | 移动高亮 |
| `Enter` | 插入高亮短语 |
| `Tab` | 插入高亮短语 |
| `Esc` | 关闭面板，不插入 |
| `Shift + Tab` | 关闭面板 |
| `Shift + Enter` | 不拦截，交给输入框换行 |

面板打开时，这些按键不会触发 Harness 的发送或焦点切换。

## 工具行按钮

输入框工具行左侧有一个触发按钮：

- 显示第一个触发符
- 点击会先把焦点还给输入框，再插入第一个触发符并打开面板
- tooltip 列出全部触发符

## 编辑短语

两个入口，共用同一份数据：

- 面板右下角「编辑短语」：打开编辑对话框
- 「设置 → 常用短语」：打开同一个编辑器

可以：

- 增加、删除触发符
- 增加、编辑、删除、上移、下移短语
- 为每条短语设置简码、名称、正文
- 保存、撤销、重新加载

未保存的修改在「重新加载」或外部数据更新时会被覆盖。

## 插入行为

- 触发符和查询文本整体替换为短语正文
- 正文按纯文本插入；多行文本的行为与粘贴多行文本一致
- 插入后菜单保持关闭，直到下一次输入
- 短语只保存在本机，不会进入模型上下文，也不随会话同步
